## Deployment

The existing Cloudflare Pages project serves this website. Its production branch is main, its output directory is public, and no build command is configured. Automatic deployments are enabled.

Keep the existing Pages project and domains in place during the transition. A repository rename does not require renaming internal CSS classes, JavaScript identifiers or asset filenames.

## Design preservation
